# Servio (by ServioHQ) v1.20 — Capacitor Mobile Project

## Quick Start Commands
1. Open Command Prompt or PowerShell in this `servio-mobile` folder:
   npm install

2. Generate the native mobile project(s):
   npx cap add android
   npx cap add ios
   npx cap sync

3. Open in Android Studio or Xcode:
   npx cap open android
   npx cap open ios
